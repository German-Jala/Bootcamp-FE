Phase 4 Module 13: Two-Way Binding

Objective: Your goal is to build a search filter for your recipe box.

src/app/recipe-list/recipe-list.ts import FormsModule and add it to your component imports. Define a new writable signal searchTerm of type string, initialized to an empty string ''. Create a computed signal called filteredRecipes that dynamically returns a filtered array of your recipes list based on whether the recipe name includes the searchTerm value (case-insensitive).

Update the template in src/app/recipe-list/recipe-list.html to add an input text field at the top of the sidebar. Bind this input to your searchTerm signal using two-way binding. Update your template buttons to loop over the new filteredRecipes() computed signal instead of the static recipes() list.

Expected Outcome: When you are finished, typing in the search input box should instantly filter the recipe list in the sidebar. For example, typing "Carbonara" should hide "Caprese Salad" and only show the Spaghetti option. Clearing the text box should immediately display all recipes again.
