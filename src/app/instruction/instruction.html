Phase 4 Module 16: Adding New Recipes

Objective: Your goal is to build an AddRecipe component that allows users to add new recipes to the application.

  1. Refactor the Service:

    Open src/app/recipe.ts. Change the recipes property to a writable signal containing MOCK_RECIPES. Implement an addRecipe(newRecipe: Omit{{ '<' + 'RecipeModel, \'id\'>' }}) method that generates a unique id (e.g., matching the array length + 1), constructs a new RecipeModel object, and updates the recipes signal by appending the new recipe.

  2. Expose Service Signal:

    In src/app/recipe-list/recipe-list.ts, update the recipes signal to read from the service signal directly: recipes = this.recipeService.recipes; (so it automatically updates).

  3. Build the Form:

    In AddRecipe, inject FormBuilder and Recipe (the service). Build a form group containing controls for name, description, imgUrl, and isFavorite. Add validators to ensure name and description are required.

  4. Wire Form Template:

    In add-recipe.html, create a form layout with input fields for each form control, binding them using formControlName. Add a submit button.

  5. Handle Submit:

    In the submit handler, call your service's addRecipe() method passing the form values, then navigate back to /recipes (hint: inject the Angular Router service and call this.router.navigate(['/recipes'])).

  6. Add Route:

    Register add-recipe as a path mapping to AddRecipe inside src/app/app.routes.ts.

Expected Outcome:

When you navigate to http://localhost:4200/add-recipe, you should see your input form. Filling out the form and clicking submit should add the new recipe to your service's state, and redirect you back to /recipes where the new recipe should immediately appear in the sidebar list.
