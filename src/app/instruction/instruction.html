Phase 4 Module 17: Intro to Angular Material

Note: During the prompt, choose any pre-built theme you like (or accept the default) and select yes to set up global typography. The CLI will automatically update your package.json and styling sheets.

Objective: Your goal is to replace a standard HTML button in your application with a styled Angular Material button.

  1. Select a Button:

    Choose a component (e.g., the submit button in src/app/add-recipe/add-recipe.html or the servings adjustment buttons in src/app/recipe-detail/recipe-detail.html).

  2. Import Material Module:

    Import MatButtonModule from '@angular/material/button' in that component's .ts file and add it to the imports array.

  3. Update the Template:

    Update the button template to use a Material directive, such as mat-raised-button or mat-flat-button.

Expected Outcome:

When you compile the app, the buttons you updated will render with modern Material Design typography, animations (ripple effects), and professional visual styling instead of standard browser-default button boxes.
