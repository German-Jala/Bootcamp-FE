Phase 4 Module 15: Basic Routing

Objective: our goal is to convert your recipe box into a multi-page app with full URL-based routing.

Open the newly generated

  1. Configure Routes:

    Open src/app/app.routes.ts and add paths for:
    • /recipes mapping to RecipeList.
    • /recipes/:id mapping to RecipeDetail.
    • An empty path '' redirecting to /recipes with pathMatch: 'full'.

  2. Update Root Component:

    In src/app/app.ts, import RouterOutlet from '@angular/router' and add it to imports. In src/app/app.html, replace the {{'<' + 'app-recipe-list>' }} tag with {{ '<' + 'router-outlet>' + '<' + '/router-outlet>' }}. (Keep {{'<' + 'app-instruction>' }} at the top).

  3. Refactor RecipeList:

    • In src/app/recipe-list/recipe-list.ts, import RouterLink and add it to the imports array. Remove the RecipeDetail child component from the imports since it is now loaded via routing.
    • In src/app/recipe-list/recipe-list.html, remove the {{'<' + 'app-recipe-detail><' + '/app-recipe-detail>' }} element. Replace the buttons with links or style the button wrappers to use [routerLink]="['/recipes', recipe.id]" to trigger route changes on click.

  4. Refactor RecipeDetail:

    In src/app/recipe-detail/recipe-detail.ts, remove the signal input() for the recipe.

    Inject both the ActivatedRoute and the Recipe data service.

    Define a local recipe signal (e.g., protected readonly recipe = signal{{'<' + 'RecipeModel | null>' }}(null); or handle it gracefully).

    Implement OnInit and read the id param from the route snapshot. Query the Recipe service's recipes list to find the recipe whose id matches (convert the parameter string to a number using Number(id)) and set your local recipe signal.

Expected Outcome:

When you navigate to http://localhost:4200/recipes, you should see your recipe list. Clicking "Spaghetti Carbonara" should change the browser's address bar to http://localhost:4200/recipes/1 and render the details for Spaghetti Carbonara. Using the browser's back button should return you to the full list.
