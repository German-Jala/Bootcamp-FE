Phase 3 Module 8: Component Inputs with Signals

Project Exercise

Objective: Your goal is to separate the detailed view of a recipe from the list view.

  1. Define a required recipe input of type RecipeModel in the new RecipeDetail component using the signal input() API.
  2. Move the servings state (servings signal), the ingredient recalculation logic (adjustedIngredients computed signal), and the servings adjustment helper method from RecipeList into RecipeDetail, making them local to the detail component.
  3. Move the HTML markup that renders the recipe details (name, description, image, servings, and ingredients) from RecipeList's template to RecipeDetail's template.
  4. Finally, nest {{ "<" + "app-recipe-detail>" }} inside your RecipeList template and pass the active recipe to it using property binding.

Expected Outcome: When you are finished, the application should function exactly as before: clicking between recipe buttons should swap the active recipe details, and adjusting the servings should recalculate ingredient amounts. However, your code is now highly modular: RecipeList only handles recipe selection, while RecipeDetail manages the servings adjustment and detailed display. Give it a shot!
